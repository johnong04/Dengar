# Slice 17 — static-node mode · gate: smoke · overnight-eligible: yes

Constraints: see v2-full-COMMON.md — read it first.

## Outcome
specs §2's secondary capture mode, and one of the project's best arguments: the drawer of dead phones
in every Malaysian household becomes fixed surveillance infrastructure at zero hardware cost.

- `/node/setup` — a short flow, citizen warm register: where to place it (beside standing water or a
  dark container, face-up, ~5 cm above the lure — the geometry published accuracy was measured under),
  keep it plugged in, how long. Honest framing throughout: this is a *placed sensor*, never "scanning
  the area" (§2).
- `/node/running` — the "leave this phone here" state: the screen it shows while working. Large, calm,
  glanceable from across a room: listening state, elapsed duration, detections so far, battery, a
  `stop` action. This state doubles as a video shot, so it must look good at a distance — bigger type
  than any other screen in the app.
- Entry point: the capture screen's quiet secondary line ("Have an old phone? Set up a static node").
- Simulated detections tick up while running (declared).

## Acceptance (one line)
Setup flow completes into the running state; running state legible at arm's length and beyond;
screenshots `17-node-setup.png`, `17-node-running.png`; `npm run check` green.
