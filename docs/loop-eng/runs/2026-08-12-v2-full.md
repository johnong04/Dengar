## Process — what changed this run

- **Agents no longer commit.** Four parallel agents racing on `index.lock` is a failure mode with no
  upside. Agents report explicit paths; the orchestrator stages and commits. Side effect worth
  keeping: the orchestrator writing the message kept each commit honest about the slice's *unverified*
  parts, which a self-reporting agent tends to omit.
- **Parallel dispatch of 4 mutually-independent slices worked with zero conflicts**, given per-agent
  playwright sessions and one shared dev server nobody restarts.
- **Entry-point wiring was held back to the orchestrator** because two slices both wanted `index.tsx`.
  Typed routes reject links to routes that do not exist yet, so it had to run last regardless.
- **Slice 21 ran as a single pass** (critique+fix in one agent, no separate evaluator) at John's
  request to close the run. It still found and fixed 4 defects, including one a previous slice had
  claimed to fix. The cost is that 21's own fixes went unreviewed.
